Rythra and its players emit various events to keep you informed about what's happening.

## Rythra Manager Events

Listen for manager-level events like node connections or player creations.

<Tabs>
<TabItem label="TypeScript">
```typescript
rythra.on("nodeCreate", (node) => {
    console.log(`Node ${node.options.identifier} created.`);
});

rythra.on("nodeConnect", (node) => {
    console.log(`Node ${node.options.identifier} connected.`);
});

rythra.on("nodeError", (node, error) => {
    console.error(`Node ${node.options.identifier} error:`, error);
});

rythra.on("playerCreate", (player) => {
    console.log(`Player created for guild ${player.guild}..`);
});
```
</TabItem>

## Player Events

Listen for playback-related events on individual players.

<Tabs>
<TabItem label="TypeScript">
```typescript
player.on("trackStart", (track) => {
    console.log(`Started playing: ${track.info.title}`);
});

player.on("trackEnd", (data) => {
    console.log(`Track ended. Reason: ${data.reason}`);
});

player.on("trackError", (data) => {
    console.error("Playback error:", data.error);
});

player.on("trackSkip", (track) => {
    console.log(`Skipped: ${track.info.title}`);
});
```
</TabItem>
<TabItem label="ESM">
```javascript
player.on("trackStart", (track) => {
    console.log(`Started playing: ${track.info.title}`);
});

player.on("trackEnd", (data) => {
    console.log(`Track ended. Reason: ${data.reason}`);
});

player.on("trackError", (data) => {
    console.error("Playback error:", data.error);
});

player.on("trackSkip", (track) => {
    console.log(`Skipped: ${track.info.title}`);
});
```
</TabItem>
<TabItem label="CJS">
```javascript
player.on("trackStart", (track) => {

player.on("trackEnd", (data) => {

});

player.on("trackError", (data) => {

player.on("trackSkip", (track) => {

});
```
</TabItem>
