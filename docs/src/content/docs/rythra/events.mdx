Rythra and its players emit various events to keep you informed about what's happening.

## Rythra Manager Events

Listen for manager-level events like node connections or player creations.

<Tabs>
<TabItem label="TypeScript">
```typescript
rythra.on("nodeCreate", (node) => {
    console.log(`Node ${node.options.identifier} created.`);
});

rythra.on("nodeConnect", (node) => {
    console.log(`Node ${node.options.identifier} connected.`);
});

rythra.on("nodeError", (node, error) => {
    console.error(`Node ${node.options.identifier} error:`, error);
});

rythra.on("playerCreate", (player) => {
    console.log(`Player created for guild ${player.guild}..`);
});
```
</TabItem>

## Player Events

Listen for playback-related events on individual players.

<Tabs>
<TabItem label="TypeScript">
```typescript
player.on("trackStart", (track) => {
    console.log(`Started playing: ${track.info.title}`);
});

player.on("trackEnd", (data) => {
    console.log(`Track ended. Reason: ${data.reason}`);
});

player.on("trackError", (data) => {
    console.error("Playback error:", data.error);
});

player.on("trackSkip", (track) => {
    console.log(`Skipped: ${track.info.title}`);
});
```

### Common Event Data

Many player events provide the current `track` and additional metadata about the event.

## Node Lifecycle

Nodes expose an explicit lifecycle state rather than a single boolean. Every change emits `state` on the node and `nodeState` on the manager, and `node.connected` is `true` only while the node is `ready`.

```
disconnected → connecting → ready
                   ↓          ↓
                degraded ←────┘
                   ↓
             (reconnect) → connecting
```

| State | Meaning |
| --- | --- |
| `disconnected` | Idle: no socket and no pending reconnect. |
| `connecting` | Detecting the Lavalink generation and opening the socket. |
| `ready` | Handshake accepted; the node accepts players. |
| `degraded` | The socket dropped and a reconnect is scheduled. |
| `draining` | An explicit `disconnect()` is in progress. |

```typescript
rythra.on("nodeState", (node, state, previous) => {
    console.log(`${node.label}: ${previous} -> ${state}`);
});
```

### Manager Event Reference

| Event | Arguments | Emitted when |
| --- | --- | --- |
| `nodeCreate` | `node` | A node is registered. |
| `nodeReady` | `node`, `payload` | Lavalink sent the `ready` opcode. |
| `nodeVersion` | `node`, `apiVersion`, `serverVersion` | The Lavalink generation was detected. |
| `nodeState` | `node`, `state`, `previous` | The node lifecycle state changed. |
| `nodeDisconnect` | `node` | The node socket closed. |
| `nodeReconnectFailed` | `node` | Reconnect attempts were exhausted. |
| `nodeError` | `node`, `error` | The node reported a transport or decode error. |
| `playerCreate` | `player` | A guild player was created. |
| `playerDestroy` | `player` | A guild player was destroyed. |
| `destroy` | – | The manager finished shutting down. |
