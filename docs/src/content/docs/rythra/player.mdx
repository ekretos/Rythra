import { Tabs, TabItem } from '@astrojs/starlight/components';

The `RythraPlayer` class is responsible for managing audio playback in a specific guild.

## Managing Playback

### Playing Tracks

You can play a track by passing its encoded string or a `Track` object to the `play` method:

<Tabs>
<TabItem label="TypeScript">
```typescript
// Play a track directly
await player.play(track);

// Add to queue and play if nothing is playing
player.queue.add(track);
if (!player.playing) await player.play();
```
</TabItem>
<TabItem label="ESM">
```javascript
// Play a track directly
await player.play(track);

// Add to queue and play if nothing is playing
player.queue.add(track);
if (!player.playing) await player.play();
```
</TabItem>
<TabItem label="CJS">
```javascript
// Play a track directly
await player.play(track).catch(console.error);

// Add to queue and play if nothing is playing
player.queue.add(track);
if (!player.playing) player.play().catch(console.error);
```
</TabItem>
</Tabs>

## Queue Management

The `player.queue` object allows you to manage the list of upcoming tracks.

<Tabs>
<TabItem label="TypeScript">
```typescript
// Add a track to the queue
player.queue.add(track);

// Clear the queue
player.queue.clear();

// Get the number of tracks in the queue
console.log(`Queue length: ${player.queue.length}`);
```
</TabItem>
<TabItem label="ESM">
```javascript
// Add a track to the queue
player.queue.add(track);

// Clear the queue
player.queue.clear();

// Get the number of tracks in the queue
console.log(`Queue length: ${player.queue.length}`);
```
</TabItem>
<TabItem label="CJS">
```javascript
// Add a track to the queue
player.queue.add(track);

// Clear the queue
player.queue.clear();

// Get the number of tracks in the queue
console.log(`Queue length: ${player.queue.length}`);
```
</TabItem>
</Tabs>
